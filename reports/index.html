Benchmarks of the two APIs of mongo-predict: 00 covers the embeddings API (pymongopredict.embeddings_api), 01 the predictions API (pymongopredict.predictions_api). Each report is self-contained; open it for methods, numbers and how to reproduce them.

Wrapper speed of the embeddings API (MongoDataset, train_test_split, DocumentFeaturizer) on the 14 MongoDB sample tasks, in memory and streaming, before and after the performance work.

01 · Predictions API: $predict
01_predictions_api.html · src/predictions_api_report.py
A $predict aggregation stage modelled on $vectorSearch: stored prediction models, the stage run on the client and the rest of the pipeline on the server; overhead and agreement on the 14 sample tasks and a voyage-4-nano example.
Highlight: same predictions as the client-side code on all 14 tasks at a median 1.39x its time; a model trained outside Porto labels Porto's Airbnb listings with accuracy 0.924.
