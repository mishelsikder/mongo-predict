pymongopredict

pymongopredict: predictive models on MongoDB collections.

Predict a field of your documents (a class or a number) from the other fields and from embeddings of the document text, and use the predictions in MongoDB.

The package has two APIs over the same featurizer:

  • pymongopredict.predictions_api: a $predict aggregation stage, modelled on Atlas $vectorSearch, backed by prediction models stored in the database. Define a model with create_prediction_model(PredictionModel(definition, name)), then use {"$predict": {"model": name, ...}} as the first stage of an ordinary pipeline and read the predictions with {"$meta": "prediction"}. No server changes are needed.
  • pymongopredict.embeddings_api: the scikit-learn workflow underneath it (MongoDataset, DocumentFeaturizer, MongoSeries; splits come from scikit-learn) for fitting any sklearn estimator or sktime forecaster on columns plus document embeddings.

Everything in embeddings_api.__all__ and predictions_api.__all__ is importable from here.

The README (README.md) introduces the package with an example on sample_mflix.movies. These pages are the reference: pymongopredict.predictions_api and pymongopredict.embeddings_api.

Install

The package is not on PyPI yet; install it from GitHub (Python 3.10 or later):

pip install "pymongopredict @ git+https://github.com/voyage-ai/mongo-predict"
pip install "pymongopredict[sktime] @ git+https://github.com/voyage-ai/mongo-predict"   # + sktime for forecasting

Demos

The demos use the MongoDB sample datasets. On Atlas you can load them from the cluster menu; for a local server the loader copies the same collections from a public mirror. Run them from the repository root:

uv sync --all-extras --group dev
uv run python -m demos.load_sample_data --uri mongodb://localhost:27017 sample_mflix sample_airbnb sample_weatherdata
uv run python -m demos.predictions_api.movie_ratings --uri mongodb://localhost:27017
uv run python -m demos.predictions_api.predict_stage --uri mongodb://localhost:27017
uv run python -m demos.embeddings_api.airbnb_room_type --uri mongodb://localhost:27017
uv run python -m demos.embeddings_api.weather_timeseries --uri mongodb://localhost:27017

Add --embedding-model hashing to skip downloading the embedding model, --dimension 512 for smaller embeddings, or --streaming to fetch documents in batches. The results below use voyage-4-nano (2048 dimensions) on one H100.

Predictions API: movie ratings (demos/predictions_api/movie_ratings.py)

The README's example: a model trained on the 17,527 movies of sample_mflix.movies released before 2010 from the embedding of each movie (title, year, runtime, age rating, genres, cast, directors and plot, all in embedFields), and $predict rating the 5,914 released from 2010 on (the other ratings in the documents are not used).

Predictions API: Airbnb listings (demos/predictions_api/predict_stage.py)

A room type model trained on every market except Porto (5,001 listings; accuracy 0.920 on held-out listings), then $predict on Porto's 554 listings: the most confident predictions with $sort on predictScore, actual against predicted with $group (accuracy 0.912), and the predictions written to sample_airbnb.listings_predictions with $merge. With the embeddings cached (MONGOPREDICT_PREDICT_CACHE_DIR set for $predict), fitting the default XGBoost model takes about 50 s and each pipeline under 1 s on 16 CPU threads.

Development

uv sync --all-extras --group dev
uv run pytest -n 4                                              # tests on mongomock, no network or GPU needed
MONGOPREDICT_TEST_URI=mongodb://localhost:27017 uv run pytest   # also the tests against a real server
uv run ruff check .
bash docs/build_docs.sh                                         # rebuild these pages
  • voyage-4-nano is loaded through sentence-transformers with trust_remote_code=True; its code needs transformers<5, which the package pins.
  • Set HF_HOME if the default Hugging Face cache is not writable.
Examples

Usage:

from pymongopredict import PredictionModel, predictions_api

predictions_api.enable()  # coll.aggregate() now understands $predict
movies.create_prediction_model(PredictionModel(
    {"target": "imdb.rating", "embedFields": ["plot", "genres"]}, name="imdb_rating",
))
movies.aggregate([
    {"$predict": {"model": "imdb_rating", "filter": {"year": {"$gte": 2010}}}},
    {"$sort": {"p": {"$meta": "prediction"}}},   # best predicted first
    {"$limit": 10},
    {"$project": {"title": 1, "predicted_rating": {"$meta": "prediction"}}},
])
